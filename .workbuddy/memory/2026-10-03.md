## dream-admin：补上插件卡片图标与展示文案

参照 `D:\HarnessPluginProject\ContextDistiller` 的做法给 DreamAdmin 加了插件卡片美术：

- 新增 `assets/icon.svg`（36×36，透明底，实心 + 单条线性渐变 `#67C7FE→#3F77D8`）：
  一张折角文档 + 一条镂空行 + 一枚月牙镂空 = 「记忆（Markdown 文件）里装着梦」。
  选型过程：比过「月牙 + 记忆条」「纯文档」「文档 + 星芒」等 10 余个方案，
  最后按「单轮廓 + 负空间缩到 20px 仍可辨认」的原则定稿（并排两元素在 20px 会糊）。
- 新增 `locale/en.json`（DreamAdmin / 英文描述）与 `locale/zh.json`（记忆管理 / 中文描述）。
- `package.json`：加顶层 `"icon": "./assets/icon.svg"`；`exports` 放行 `./locale/*.json`；
  `files` 加 `assets` 与 `locale/*.json`（漏了这两处，发布后的包就没卡片美术/文案）。
- `scripts/gates/run.mjs`：移植 ContextDistiller 的 icon + locale 门禁（含 `ships()` 判定
  `files` 是否真的发出该文件），并做了三次反向测试（删图标 / 删 en.json / 删 exports 放行）
  确认会 RED，恢复后 PASS。

验证：`node scripts/gates/run.mjs` → GATE PASSED。
截图对比用系统 Chrome 无头模式（`--headless=new --screenshot`）渲染多尺寸 + 明暗底 + 卡片上下文。

未改动：`src/client/index.ts` 里侧边栏用的 `DreamAdminIcon`（16px 线性 currentColor 图标）
保持原样，与卡片彩色图标是两套语境，暂无需要统一。

## 本机环境备忘（Windows）

- Bash 工具默认 PATH 缺失，`ls`/`cat` 等会 command not found：
  命令前加 `export PATH="/usr/bin:/bin:$PATH"` 即可。
- PowerShell 工具这次拿不到 stdout（只回 exit code），要看输出就重定向到文件再读。
